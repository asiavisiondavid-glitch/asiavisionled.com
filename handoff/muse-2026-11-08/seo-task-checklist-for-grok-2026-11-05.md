# 给 Grok 的网站 SEO 任务清单（2026-11-05）

## 任务一 P0：20 个页面 title / meta 重写（最优先）

详细清单见附件 `seo-p0-title-meta-rewrite-brief-2026-11-04.md`，每个页面给了：当前数据、匹配的搜索词、建议 Title、建议 Meta、中文说明。

**执行要求：**
1. 20 个页面逐一按清单改 title 和 meta description
2. Title ≤ 60 字符（含空格），Meta 150–160 字符
3. 清单里的 Title/Meta 是方向稿——必须对照页面实际内容微调，确保标题与正文一致，不虚假承诺
4. 清单中数字（如 500×500、8531.20）是通用行业表述，**不是公司规格**，如页面内容无对应数据则删掉数字、改通用表述
5. 四条重写原则：关键词前置 40 字符内；加数字/年份/地域；植入"深圳工厂直供、OEM/ODM、3 年质保"差异化；Meta 带行动召唤、不堆关键词
6. 改完后在 Search Console 里请求重新索引这 20 个 URL

**预期效果：** 这 20 页目前 3,335 曝光仅 18 点击（CTR 0.54%），目标 CTR 3%，预计 3 个月点击 18 → 约 100。

**特别注意第 2 项（首页）：** 品牌词 "asia vision" 有 49 曝光、0 点击，首页只排第 10.9 名——title 必须品牌词前置，这是全站最重要的一个 title。

2. 检查是否有测试环境的 GA4 代码误装到正式站

## 任务三 P1（做完 P0 后）：产品页 title 优化

首页改完后，按同样四原则优化核心产品页（COB 小间距、租赁屏、室内外固装屏）的 title/meta，植入工厂、OEM、3 年质保。

## 任务四 P2（内容方向）：加码 UAE / 新加坡

Search Console 显示 UAE（CTR 3.15%）、新加坡（CTR 3.93%）是点击率最高的两个市场。后续博客选题优先写这两地的市场、进口、案例类内容。

## 任务五 P3（转化）：文章内嵌 WhatsApp 入口

博客是全站 90% 曝光来源。在高曝光文章（尤其 Top 20 清单里的）文末加一段 CTA，引导留 WhatsApp 或邮件询盘，把流量转成询盘。
